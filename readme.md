#  Paddock Pass (F1 Telemetry)

## Project Overview
**Purpose & Problem Solved:**  
Motorsport enthusiasts and race engineers often need a quick, lightweight way to log and analyze lap times during a practice session. Paddock Pass solves this by providing a fast, client-side telemetry dashboard. It allows users to record driver stints (lap times and tyre compounds) and instantly calculates overall session statistics.

## Features
* **Data Entry (Log Lap):** A user-friendly form to input driver name, lap time, and tyre compound.
* **Dynamic Dashboard:** Automatically calculates the total laps logged and identifies the overall fastest lap across all entries.
* **Session History:** Displays all recorded telemetry in a clean, organized data table.
* **Analytics:** Filter lap records dynamically in real-time by typing a driver's name.
* **Data Persistence:** All logged data is saved to the browser's `localStorage`. Session data remains fully intact even if the browser tab is refreshed or closed.
